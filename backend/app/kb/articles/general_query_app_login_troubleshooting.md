---
title: Mobile App and Login Troubleshooting
category: general_query
---

Most login issues are resolved by confirming the customer is using the
correct registered email (not a typo'd variant) and that their app is
updated to the latest version — outdated app versions occasionally lose
compatibility with current login security requirements.

If the customer sees a generic "something went wrong" error rather than
an explicit invalid-password message, the issue is more likely a network
or app-version problem than an incorrect password, and a fresh app
install often resolves it.

Only escalate a login issue as a potential account lock if the app
explicitly shows a locked-account message — a generic error alone is not
enough to assume the account is locked.
