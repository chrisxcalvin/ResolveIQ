---
title: How to File a Transaction Dispute
category: dispute
---

A dispute should only be filed for a transaction the customer does not
recognize, was charged incorrectly, or where a merchant failed to deliver
goods/services as promised — not for a transaction the customer simply
regrets making, since that is not a valid dispute reason under card
network rules.

To file a dispute, the customer needs the transaction date, amount, and a
short description of the issue. Filing does not guarantee a refund — it
opens a formal investigation with the card network and, where applicable,
the merchant.

Encourage the customer to try resolving the issue directly with the
merchant first when possible, since a merchant-issued refund is faster
than the dispute process and does not require an investigation.
